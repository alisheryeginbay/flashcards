# My flashcards

My flashcard collection using [Amgi](https://github.com/alisheryeginbay/amgi).

## Conventions

### CLI commands

For flashcards that require path I use either `path/to/directory` or `path/to/file`. It is not only the matter of consistency; it also helps me to avoid ambiguity. It is especially important for cards where I have to input the answer:
```md
Q: How to print the size of a file / folder?
A: [=`du -sh path/to/file`]
```
